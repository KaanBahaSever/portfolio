## Math

Math is rendered to HTML and MathML when the site is built, so pages load no math scripts.
Inline formulas sit in the sentence: to approximate $\sqrt{2}$, look for the positive root of
$f(x) = x^2 - 2$. Newton's method refines a guess $x_n$ with

$$
x_{n+1} = x_n - \frac{f(x_n)}{f'(x_n)} = \frac{1}{2}\left(x_n + \frac{2}{x_n}\right),
$$

and near the root the error is roughly squared at every step. A literal dollar sign is
written as `\$`, so a price such as \$5 stays text.

## Code

The same iteration in C++23, highlighted at build time in both colour schemes:

```cpp
#include <print>

int main() {
    double x = 1.0;
    for (int n = 1; n <= 5; ++n) {
        x = 0.5 * (x + 2.0 / x);  // one Newton step for x² = 2
        std::println("x{} = {:.15f}", n, x);
    }
}
```
